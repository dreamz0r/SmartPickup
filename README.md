# Smart Pickup

**Author:** Griffin

A lightweight DayZ mod that automatically places picked-up items in the best available location:

1. A free compatible equipment or attachment slot.
2. Existing compatible stacks, filling multiple stacks when needed.
3. Inventory cargo for any remainder.

Supports compatible vanilla and modded slots across the player and carried gear. Existing item restrictions and stack limits still apply. If cargo is full, any quantity that cannot be stacked stays at its original location.

Load the mod on both the server and clients. No extra dependencies or background inventory sorting.
